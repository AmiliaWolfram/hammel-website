HAMMEL MESSEN — ФОТОГАЛЕРЕИ

После замены файлов выполните в корне Django-проекта:
python manage.py migrate
python manage.py runserver

Важно: НЕ заменяйте и НЕ удаляйте свою db.sqlite3 и папку media/!
В форме /staff/messen/neu/ можно выбрать несколько фото галереи.
На странице редактирования можно добавить фото или отметить фото для удаления.
После окончания выставки она автоматически переходит в раздел MESSE-RÜCKBLICK.
На публичной странице /aktuelles/index.html фотографии можно листать, а нажатие увеличивает изображение.
