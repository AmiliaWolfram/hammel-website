HAMMEL HR: массовое заполнение недостающих переводов

Внимание: архив НЕ содержит рабочую базу db.sqlite3.
Сделайте резервную копию текущей базы до запуска.

1. Установите зависимость в активном .venv:
   python -m pip install deep-translator

2. Проверьте количество незаполненных полей (без изменений и сетевых запросов):
   python manage.py complete_hr_translations --dry-run

3. Запустите заполнение EN, FR, ES, IT:
   python manage.py complete_hr_translations

Переводы выполняются через Google Translate по сети. Записи сохраняются
со статусом In Prüfung. Существующие записи не перезаписываются.
Если сеть прервётся, повторите команду: уже сохранённые поля будут пропущены.
Переводы необходимо проверить перед публикацией; автоматический перевод
не гарантирует точность технических терминов.

Также в проекте есть ранее подготовленные ручные переводы:
   python manage.py import_curated_vacancy_translations
   python manage.py import_curated_hr_misc_translations
Их рекомендуется импортировать ДО массового перевода.
