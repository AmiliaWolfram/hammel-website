# HAMMEL DE — безопасное обновление переводов (этап 28)

В архиве НЕТ `db.sqlite3`. Рабочую базу не заменять.

1. Распакуйте проект поверх кода (или перенесите только `translations/management/` и `translations/data/`). Не удаляйте свой текущий каталог и базу.
2. Активируйте виртуальное окружение проекта.
3. Проверьте изменения: `python manage.py import_missing_vacancy_translations --dry-run`
4. Импортируйте: `python manage.py import_missing_vacancy_translations`

Команда сначала создаёт проверенную копию SQLite в `database_backups/`, затем добавляет только отсутствующие переводы. Существующие тексты и статусы не изменяются. Повторный запуск не создаёт дубликаты.

Включены 43 перевода названий вакансий (EN, FR, ES, IT) из этапа 27; описания и другие тексты пока НЕ переведены. Для сопоставления используется точное немецкое название вакансии. Переименованные и неоднозначные вакансии пропускаются.

Если проект использует PostgreSQL, команда откажется от записи: перед импортом нужна отдельная резервная копия PostgreSQL и соответствующий способ восстановления. Нельзя использовать SQLite-файл как замену PostgreSQL.
